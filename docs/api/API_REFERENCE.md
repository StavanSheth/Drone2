# API Reference
- `GET /health`: System and hardware status
- `GET /gps`: Live GPS coordinates
- `GET /serial-logs`: Raw ESP-NOW serial stream
- `POST /analyze-feed`: Run YOLOv8 detection on frame
- `POST /chat`: RAG Copilot query
- `GET /list-ports`: Available COM ports
- `POST /set-port`: Switch active serial port
